Projeto 02 · Site institucional

CHARGin.

Uma experiência digital premium para apresentar soluções de mobilidade elétrica, franquias e estações de recarga.

Ano
2026
Papel
Design e desenvolvimento front-end
Framework
Next.js 16 · React 19
Linguagem
TypeScript
01 / Contexto

Mobilidade com presença digital.

O CHARGin foi pensado como uma plataforma institucional completa, não apenas como uma landing page.

A experiência apresenta o aplicativo, oportunidades de franquia, solução White Label e diferentes aplicações para pontos de recarga. A identidade escura, as microinterações e o conteúdo visual posicionam a marca no universo de tecnologia premium.

02 / Experiência

Conteúdo que convida a explorar.

Mapa interativo

Pesquisa e seleção de estados sincronizadas com um mapa SVG do Brasil.

Catálogo de pontos

Páginas individuais para aplicações em hotéis, aeroportos, condomínios e outros espaços.

Jornada de franquia

Conteúdo dedicado e formulário de interesse com validação no cliente.

Solução White Label

Rota institucional própria para apresentar uma oferta B2B personalizada.

03 / Arquitetura

Performance desde a estrutura.

Server Components são o padrão; JavaScript no cliente é usado apenas onde a interação realmente exige.

O App Router organiza páginas institucionais, rotas dinâmicas e metadados. Os detalhes dos pontos de recarga são pré-renderizados, enquanto o componente de imagem do Next.js otimiza os recursos visuais.

  • Next.js 16
  • React 19
  • TypeScript
  • CSS Modules
  • App Router
  • Server Components
  • SVG Maps
  • ESLint
  • Vercel
04 / Aprendizados

O que esse projeto consolidou.

  • Arquitetura escalável com componentes, dados e tipos separados.
  • Estratégia de renderização com Server e Client Components.
  • Rotas dinâmicas, geração estática e metadados orientados a SEO.
  • Interfaces responsivas e acessíveis com alto cuidado visual.
