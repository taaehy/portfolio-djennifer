Projeto 03 · Plataforma full stack

Lume.

Gestão de qualidade de software em um fluxo único para acompanhar bugs, registrar testes e avaliar releases com mais clareza.

Ano
2026
Papel
Design e desenvolvimento full stack
Framework
Next.js · React
Dados
Prisma · PostgreSQL
01 / Contexto

Qualidade sem informação dispersa.

O Lume reúne o trabalho de qualidade em um espaço compartilhado, do primeiro bug à decisão de liberar uma versão.

A plataforma foi criada para reduzir a fragmentação entre anotações, evidências e status. Com autenticação por e-mail e senha, cada pessoa acessa um ambiente responsivo onde o histórico do produto permanece organizado e consultável.

02 / Fluxo

Do problema à release.

Kanban de bugs

Os itens avançam por etapas visíveis, com prioridade, responsável e regras de transição.

Registro de testes

Execuções, resultados e evidências ficam associados ao contexto que precisam validar.

Avaliação de releases

Indicadores e critérios de prontidão apoiam a decisão antes de cada publicação.

Evidências privadas

Anexos permanecem protegidos e vinculados aos registros de qualidade correspondentes.

03 / Arquitetura

Produto e API na mesma base.

A aplicação combina uma interface tipada, API própria e persistência relacional para manter o fluxo consistente.

Next.js e React sustentam a experiência responsiva; Prisma organiza o acesso ao PostgreSQL hospedado na Neon. Os anexos privados usam Vercel Blob, os testes automatizados usam Vitest e a aplicação é publicada na Vercel.

  • Prisma

  • Vitest

  • Vercel
04 / Decisões

O que tornou o fluxo confiável.

  • Estados e transições explícitos para preservar o histórico de cada bug.
  • Relacionamento entre testes, evidências e releases no mesmo domínio.
  • Autenticação por e-mail e senha integrada às permissões da aplicação.
  • Testes automatizados da base de código com Vitest.
