Projeto 01 · Aplicação full stack

TaskManager.

Uma aplicação para organizar tarefas com experiência direta no front-end e uma API REST desenvolvida do zero com Node.js.

Ano
2026
Papel
Design e desenvolvimento full stack
Front-end
React 19 · Vite · CSS
Back-end
Node.js · API REST · JSON
01 / Contexto

Organização sem distrações.

O objetivo foi transformar operações de CRUD em uma experiência simples, rápida e visualmente consistente.

O TaskManager permite criar, listar, pesquisar, editar, concluir e excluir tarefas. A interface acompanha o total de itens e tarefas concluídas, comunica estados vazios e mantém o usuário informado sobre a conexão com a API.

02 / Funcionalidades

Um fluxo completo.

Gestão de tarefas

Criação, edição, conclusão e exclusão em uma única interface.

Busca em tempo real

Consulta à API por título conforme o conteúdo pesquisado.

Indicadores

Contadores de tarefas exibidas e atividades concluídas.

Estados da interface

Feedback de carregamento, erro, API online e lista vazia.

03 / Arquitetura

Front-end e API conectados.

A interface React consome uma API REST organizada em rotas, controllers, repository e camada de persistência.

O servidor utiliza os módulos nativos do Node.js, incluindo HTTP, crypto e acesso assíncrono ao sistema de arquivos. A comunicação cobre métodos GET, POST, PUT, PATCH e DELETE com suporte a CORS.

04 / Aprendizados

O que esse projeto consolidou.

  • Integração completa entre uma interface React e uma API publicada.
  • Separação de responsabilidades no back-end por camadas.
  • Validação de dados, códigos HTTP e tratamento de erros.
  • Deploy independente do front-end e do servidor.
